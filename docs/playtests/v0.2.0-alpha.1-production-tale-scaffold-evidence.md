## Export evidence protocol

CI creates exact-head Windows and Linux PCKs using Godot 4.7.1-stable. The
validator reads every PCK directory entry, scans the export log, and scans raw
archive bytes for a closed inventory of Drowned Harbor paths and identities.
Evidence records platform, source SHA, PCK size and SHA-256, export-log SHA-256,
inventory digest, file count, and zero forbidden path/marker hits. PCKs, import
caches, and evidence are never committed.
