**Status:** Definitions only; all stages blocked and inactive

## Shared invariants

Every later stage must preserve:

- Lantern House as the normal default until a separately reviewed catalog release changes it;
- Drowned Harbor hidden behind explicit internal admission until separately promoted;
- static reviewed package/provider/catalog identities;
- stable-seat ownership across disconnect, surrogate control, return, transformation, defeat, and continuation;
- state-and-RNG no-op rejection for invalid, stale, duplicate, wrong-seat, unavailable, and malformed actions;
- the four existing privacy classes;
- no private terms or desirability hints on shared output;
- named native-authority RNG streams;
- explicit save versions and migrations;
- source traceability and asset provenance;
- ordinary-export exclusion until separately authorized;
- automation classified as machine evidence only.
