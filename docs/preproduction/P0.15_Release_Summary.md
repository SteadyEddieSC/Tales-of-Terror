## Interaction boundary

The shell does not commit final movement or gameplay. A valid second confirmation emits a public prototype intent with:

- the selected synthetic action;
- the current fixture revision;
- the current stable-seat authority;
- `authoritative_commit: false`;
- `revision_bound: true`.

Preview, inspect, cancel, transcript, replay, focus movement, stale requests, wrong-authority requests, malformed requests, and unknown inputs do not mutate the fixture, replace a stable seat, or consume RNG.

## Privacy boundary

`DH-FIX-001` deliberately contains private markers. The adapter projects only the approved public and seat-public map. Tests verify that private role, objective, inventory, and hidden-route markers never enter:

- public screen snapshots;
- captions;
- transcript;
- replay;
- diagnostics;
- public events;
- recovery messaging.

This automation is not privacy certification.
