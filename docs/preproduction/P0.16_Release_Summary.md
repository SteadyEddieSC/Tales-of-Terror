## Decision boundary

`DH-FIX-002` exposes one synthetic governed priority: `record_missing_position`. The prototype does not invent additional Ledger priorities, final rules, balance, or consequences.

Inspect, preview, focus movement, cancel, transcript, and replay do not mutate fixture state, replace a stable seat, consume RNG, or increment the prototype commit count.

A valid second confirmation checks:

- source revision 21;
- stable seat `seat_02`;
- active-stable-seat actor authority;
- unchanged and currently available selected option.

The shell records one prototype result and emits the governed public event once. The event is not production gameplay authority. No production authority is created.

## Recovery boundary

Bellhouse request rejection preserves the Bellhouse decision, stable seat 2, source revision, fixture fingerprint, RNG cursor, legal option, and focus.

`DH-FIX-006` remains an independent recovery fixture for seat 6. It is never merged into the Bellhouse source state. It proves deterministic projection of:

- rejected action;
- public-safe reason;
- current legal alternatives;
- legal focus destination;
- no state change;
- no RNG change.

Recovery contains no private cause, ridicule, blame, penalty, timer loss, hidden consequence, seat reset, input lock, or deadlock.
