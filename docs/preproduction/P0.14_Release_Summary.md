## Determinism boundary

The fixture projector reads declared source paths and emits canonical projections and event payloads. It does not implement a gameplay reducer, legal-action generator, encounter engine, movement system, balance model, session authority, or production save format.

Committed fixtures advance one synthetic result revision. Invalid-action recovery advances none. Every fixture keeps the RNG cursor and stable-seat identity unchanged during projection.

## Privacy boundary

Public maps may read only public and seat-public domains. Controlled-private maps may read private state for the authorized synthetic seat. Public and diagnostic events may not read private state.

The private bargain fixture emits a private event and a separate public resolution event. Private terms and marker values are verified absent from public projections and public event bytes.
