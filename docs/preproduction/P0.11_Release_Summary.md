## Core interaction boundary

P0.11 binds authored presentation to authoritative state without creating runtime behavior.

The authority order remains:

1. Tale and stable-seat state;
2. deterministic legal-action and transition rules;
3. privacy class and authorized surface;
4. confirmation and actor authority;
5. public or private event projection;
6. P0.10 storyboard presentation;
7. voice, audio, music, animation, and decorative treatment.

Lower layers may not invent higher-layer facts.

## Stable-seat boundary

Disconnect, game control, takeover, return, Tidebound transformation, defeat, Restless continuation, and ending attribution preserve the same stable seat and evolved state.

No trace authorizes:

- character replacement;
- reroll;
- healing;
- restored inventory;
- objective or faction reset;
- removed history;
- lost ending identity;
- spectator elimination.

## Privacy boundary

Public projections contain public state only.

Private bargain terms and inherited private-state handoffs require:

- a neutral shared-screen shield;
- one authorized stable seat and controller;
- acknowledgement before commitment;
- private-content clearing before public restoration;
- exclusion from public transcript, captions, audio, replay, mirroring, and screenshots.

## Determinism and recovery boundary

Authoritative commits require deterministic source and result revisions, exactly-once event identity, idempotent reprojection, and no partial commit.

Recovery preserves:

- no hidden penalty;
- no private leakage;
- no stable-seat reset;
- current legal alternatives;
- deterministic focus restoration;
- persistent plain-system text;
- local shared-screen continuity when Companion is unavailable.
