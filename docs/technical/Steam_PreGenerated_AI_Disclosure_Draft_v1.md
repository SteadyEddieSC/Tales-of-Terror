# Steam Pre-Generated AI Disclosure Draft v1

**Status:** planning draft only  
**Policy release:** `AI-ART-POLICY-001`  
**Live-generated AI:** not authorized

## Draft Content Survey description

Terror Turn uses pre-generated visual artwork created with approved generative-AI image services during development. No AI artwork is generated while the game is running.

For each shipped AI-generated visual asset, the development team retains provider, model, generation-date, account, prompt, authorized source-input, transformation, and SHA-256 provenance. Assets are reviewed before use for unauthorized third-party characters, franchise identifiers, logos, trademarks, branded products, signatures, watermarks, celebrity or private-person likenesses, accidental text, substantial similarity to identifiable works, visual defects, continuity, readability, and consistency with the game's marketing materials.

Human creative work includes art direction, prompt and brief authorship, output selection and rejection, arrangement, layout, typography, masking, compositing, color decisions, animation, UI integration, quality review, and final release approval. The project does not represent machine-generated pixels as human-painted and does not assume that all machine-determined elements are copyrightable or exclusive.

## Submission checklist

Before using this text:

- replace general statements with the exact providers and content categories in the submitted build;

- confirm no retired, rejected, quarantine-only, reference-only, or developer-only asset is shipped;
- confirm mature-content disclosures remain accurate independently of AI disclosure;
